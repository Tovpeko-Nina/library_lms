# Безопасность

## Пароли

Пароли хэшируются bcrypt через Passlib. Открытые пароли не записываются в
PostgreSQL и не возвращаются в HTTP-ответах.

Пароль должен содержать не менее 12 символов и не более 72 байт в UTF-8 — это
техническое ограничение bcrypt. Принудительные требования к регистру и
специальным символам не используются: длина важнее формальной сложности.
Проверка по базам скомпрометированных паролей пока не реализована.

`password_hash` и служебная версия JWT исключаются из пользовательских
HTTP-ответов, в том числе из административного списка пользователей.

## Первый администратор

Пароль администратора не хранится в `.env`. После запуска базы первый
администратор создаётся командой:

```bash
python -m app.cli.create_admin
```

В Docker Compose:

```bash
docker compose exec library-lms python -m app.cli.create_admin
```

Команда использует скрытый ввод `getpass`; пароль не попадает в список
процессов и историю shell.

## JWT

JWT подписывается HS256 случайным `SECRET_KEY` длиной не менее 32 символов.
Токен содержит `sub`, `iss`, `aud`, `iat`, `exp`, `jti`, роль и версию токена.
Время жизни по умолчанию — 30 минут. Смена пароля и logout увеличивают
`users.token_version`, поэтому ранее выданные токены перестают приниматься.

## Секреты

`.env` исключён из Git. На Linux следует ограничить его права:

```bash
chmod 600 .env
```

В production секреты должны передаваться через средство управления секретами
или защищённый файл окружения службы, а соединения HTTP и PostgreSQL должны
использовать TLS.

## Известные ограничения учебной версии

- JWT пока хранится в `localStorage`; это требует особенно строгой защиты от XSS.
- Нет распределённого rate limiting для входа; его следует реализовать через
  Redis или reverse proxy перед публичным развёртыванием.
- Нет MFA и восстановления пароля через подтверждённый канал.
- DDL пока выполняется приложением при старте; в ЛР3 схема будет передана
  миграциям и runtime-пользователь PostgreSQL сможет получить меньшие права.
- Политики TLS, firewall и разделение серверов оформляются в ЛР2.
